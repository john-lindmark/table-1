Table 1, everything it does

Table 1 is a suite for competitive Magic: The Gathering players: a tournament runner first, with a card library (collection, binders, wants, decks, cubes and trades), metagame and draft insights, and friends alongside. The same features run on iOS, Android and the web from one shared backend; where a feature isn't on every platform yet, its section says so.
