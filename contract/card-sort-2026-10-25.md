# Sort in View, every card list (2026-10-25)

Client-only: no server change. Cases `testdata/card-sort/cases.json` (iOS `CardSortTests`, web `cardSort.test.ts`,
Android `CardSortTest`).

## Where

The View menu on every card list gets Sort, after Group by: your decks and cubes, your binders (Unsorted too), All
cards, and everything shared with you on a profile or by link (All cards, For trade, Wants, binders, decks, cubes).
Group by still makes the sections; Sort orders the cards inside each section (and inside a deck's or cube's boards).
Grid and stacks follow it too (stacks of ten in sort order; All cards sorted by set stacks one per set, as before).

## Options (menu titles)

- **Sort by name** (A–Z, ignoring case).
- **Sort by mana value**: spells low to high, then lands (a land that isn't a creature, Group by's Lands), then by name.
- **Sort by set**: newest set first (release date), then set code A–Z, then collector number (its digits as a number,
  then the whole number as text), then name. The printing that sorts is the one shown: a deck or cube line's printing;
  in collections and binders the card's picture (the printing owned most). A card newer than the local card data has
  no set and goes last.

Screens that had their own order keep it as the first option and the default:

| Screen | Options | Starts on |
|---|---|---|
| Your decks, your cubes | Name, Mana value, Set | Name |
| Shared sections (decks, cubes and card sections) | Name, Mana value, Set | Name |
| Binders | Most copies first, Name, Mana value, Set | Most copies first |
| All cards | Most recent first, Highest price first, Name, Mana value, Set | Most recent first |

All cards' Recent / Price / Set row stays and gains Name and MV (Recent · Price · Name · MV · Set, the same setting as
the menu). Settings are kept per device like Group by: one for decks, one for cubes (shared between your own and
shared ones), one each for All cards (its existing sort), binders and shared card sections.

Telemetry `card_sort_changed` (`sort`, `screen`).
