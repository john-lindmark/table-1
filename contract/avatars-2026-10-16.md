# Avatars (2026-10-16)

Every player has an avatar: a square tile (zero radius, no border, no shadow) with their initials, or the photo
they picked. Server: `supabase/migrations/20261016270000_avatars.sql`. Built on all three clients.

## Default: initials on a muted tile
- **Initials:** split the display name on whitespace, keep words that contain a letter or digit, take the first
  letter or digit of the first word and of the last word, uppercased. One word → one letter. Nothing → `?`.
  "Jane van Dyke" → `JD`, "jane" → `J`, "  " → `?`.
- **Seed:** the account id (lowercase uuid) when the player has an account, otherwise the lowercased, trimmed
  display name (so a guest looks the same in every event).
- **Color:** FNV-1a 32-bit over the seed's UTF-8 bytes (offset 2166136261, prime 16777619), index = hash mod 8:

  | # | Hex | |
  |---|-----|---|
  | 0 | `#4A3F6B` | violet |
  | 1 | `#5B3E5A` | plum |
  | 2 | `#63414A` | rose |
  | 3 | `#5E4A38` | umber |
  | 4 | `#4D5236` | olive |
  | 5 | `#36524A` | pine |
  | 6 | `#3A4C66` | steel |
  | 7 | `#4B4B5E` | graphite |

  All sit near the surface's lightness so the tile reads as a quiet tint, never as the teal accent.
- **Text:** white, mono, medium weight, size 0.4 × tile side, tracking 0.5. Two letters fit at 24 pt.

## Photo
- Bucket `avatars` (public), path `<user_id>/<random>.jpg`. JPEG only, ≤ 1 MB; clients send a 512 × 512
  centre crop at quality 0.8. A new random name per upload, so any cache never shows the old one.
- Public URL: `<SUPABASE_URL>/storage/v1/object/public/avatars/<avatar_url>`.
- Flow: upload → `avatar_set(p_path)` → remove `previous` from storage if it was set. Remove photo:
  `avatar_clear()` → remove `previous`.
- `profiles.avatar_url` holds the path or null (check constraint: only your own folder). Clients can no
  longer write it directly. Provider pictures (Google) are no longer copied in; old ones were cleared.
- Account deletion removes the folder (`delete-account`).

## Where it shows
- Account: a 64 pt tile in the header block above the lifetime record. Tap → menu: Take a photo / Choose from
  photos / Remove photo (when set).
- 24 pt tiles left of the name: setup players list, live and results player lists, standings, head-to-head.
- Lookup: clients read `profiles(id, avatar_url)` for the account ids on screen (batched, cached for the
  session). Guests never have photos.

## Telemetry
`avatar_photo_set` (`source`: `camera` / `library`), `avatar_photo_removed`.
