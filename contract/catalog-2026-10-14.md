# Card catalog: client contract (L0, 2026-10-14)

Plan: `table-1-context/docs/plan-collection-2026-10-14.md` §3. Server: migration `20261014150000_card_catalog.sql`, edge function `cards-sync`.

## What clients use

| Need | Use | Notes |
|---|---|---|
| Card name typeahead (web, or native without a pack yet) | `search_cards(p_query, p_limit=20)` | Needs ≥ 2 normalized characters. Prefix matches first, then fuzzy (trigram). Tokens and art cards sort last. |
| All printings of a card, with prices | `card_printings(p_oracle_id)` | Newest first. USD and EUR, non-foil and foil. |
| Offline catalog (scanner, local search, filters) | `catalog_info()` → download `url` | See "Catalog pack". |
| Card image | Scryfall CDN, built from the id | See "Images". Never through our servers. |

Never call the Scryfall API from a client.

## Catalog pack (format 1)

`catalog_info()` returns `{version, format, url, bytes, sha256, oracles, printings, created_at}`, or null before the first sync.

- **When to check:** at launch, at most once a day. Download only when `version` differs from the stored one. Native clients download on Wi-Fi unless they have no pack at all. Verify `sha256` over the downloaded bytes, then swap atomically and keep using the old pack until the new one is in.
- **Size:** about 5.5 MB gzipped, 13 MB raw (2026-10: 37,866 cards, 109,573 printings). The version is a content hash, so an unchanged catalog never makes clients download.
- **Encoding:** the file is a gzip object (`application/gzip`), not HTTP Content-Encoding, so clients gunzip it themselves. UTF-8, `\n` line ends, tab-separated, no quoting. Fields never contain tabs or newlines.

```
#t1catalog  1  <version>  <oracle count>  <printing count>                         header (line 1)
O  idx  oracle_id  name  name_norm  type_line  mana_cost  cmc  colors  face_names  legal   one per card
P  card_id  oracle_idx  set  collector_number  lang  rarity  finishes  released_at  image_ts  image_faces  printed_name  original
```

- `O` lines come first, sorted by `name_norm`; `idx` counts from 0.
- `P` lines point at their card by `oracle_idx`, newest printing first within a card.
- `colors` is a string of WUBRG letters (empty = colorless). `face_names` is joined with ` // ` and is empty for single-faced cards.
- `rarity` is one letter: c, u, r, m, s (special) or b (bonus).
- `finishes` is a set of letters: n non-foil, f foil, e etched.
- `image_ts` and `printed_name` may be empty. `printed_name` is filled only for non-English printings.
- `legal` (added 2026-10-15) is one character per format, in this order: standard, pioneer, modern, legacy, vintage, pauper, commander, premodern. `L` legal, `R` restricted, `B` banned, `-` not legal. Decks flag cards that are banned or not legal in their format, and restricted cards with more than one copy across main deck and sideboard; Considering is flagged per card but doesn't count against the deck. Other formats (and cubes) are not checked.
- `original` (added 2026-10-15) is `1` on exactly one printing per card: its original paper printing, which every client uses by default when a card is added anywhere (search, decks, cubes, found decklists). Chosen on the server: the earliest English printing with an image, skipping promo, token, memorabilia (30A, CE/IE, World Championship decks), alchemy and minigame sets; the plain collector number beats variants released the same day. Falls back to the earliest English printing with an image. Every catalog printing is paper (digital-only ones are dropped at sync). Without the flag (older packs), clients fall back to the newest English printing with an image.
- Readers must ignore unknown line types and extra trailing fields. A breaking change bumps `format`.

Recommended local storage: SQLite tables `oracles(idx, oracle_id, name, name_norm, ...)` and `printings(card_id, oracle_idx, set, cn, lang, ...)`, with indexes on `name_norm`, `(set, cn, lang)` and `oracle_idx`. Insert inside one transaction (about 150k rows, well under a second).

## Name normalization (must match `public.card_name_norm`)

1. Unicode NFKD.
2. Lowercase.
3. Remove combining marks U+0300–U+036F.
4. `æ` → `ae`, `œ` → `oe`.
5. Remove apostrophes `'` and `’`.
6. Replace every run of characters outside `[a-z0-9]` with one space.
7. Trim.

Examples: `Æther Vial` → `aether vial` · `Lim-Dûl the Necromancer` → `lim dul the necromancer` · `Urza's Saga` → `urzas saga` · `Fire // Ice` → `fire ice`.

Face names are searchable on their own: "insectile" finds Delver of Secrets, and "ice" finds Fire // Ice.

## Images

`https://cards.scryfall.io/{size}/{face}/{id[0]}/{id[1]}/{id}.jpg?{image_ts}`

- `size` is `small`, `normal` or `large`; `face` is `front` or `back`.
- There is a back image only when `image_faces = 2`; `image_faces = 0` means no image.
- `id[0]` and `id[1]` are the first two characters of the card id.
- Cache on disk. `image_ts` changes when Scryfall replaces an image (preview → high-res scan); the pack carries it so cached images stay fresh.

## Card corners
Card images are drawn with rounded corners. The radius is a fraction of the drawn width, measured from Scryfall's transparent PNG scans (2026-10-15):

| Printings | Radius |
|---|---|
| Alpha (`lea`) | 6.99% of width (≈4.4 mm), rounder than everything since |
| Collectors' / International Edition (`ced`, `cei`) | 0, cut square |
| Everything else | 4.32% of width (≈2.7 mm) |

The JPG renditions have square corners filled with border color, so clients clip them. Overlays such as count tags sit inset by about 5% of the width so the rounding never clips them.
