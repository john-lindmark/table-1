### Scrubbing the guide

`make_guide.py` drops What's new and Status, the New/Updated tags and status chips, any sentence or parenthesis about
builds, releases, testing, dates, the team or how something was made (its `DROP` patterns), the entries and
subheadings listed in `tools/support/scrub.json` `drop`, rewrites the passages in `replace`, renames sections in
`titles`, and writes "color". It then fails if anything matches `scrub.json` `forbidden`; the web's `support.test.ts`
checks both files against the same patterns. **After updating the Feature Guide**: save its HTML (Artifact read), run
`make_guide.py`, read the diff of guide.json (add a drop/replace rule for anything not meant for players), then
`python3 testdata/support-search/make_cases.py`, and run the three clients' Support tests.

## Search

One rule, reference `testdata/support-search/make_cases.py` → `cases.json` over the real files (iOS `SupportTests`,
Android `SupportTest`, web `support.test.ts`):

- **Words**: NFKD, combining marks (U+0300–036F) dropped, lowercase, apostrophes (' and ’) removed, any other
  character not a–z or 0–9 splits.
- **Query words**: the query's words without the stop words (a, an, the, and, or, of, to, in, on, for, with, my, me,
  i, is, it, do, does, how, can, what, why, when, where, you, your, are, be, at, by, from, this, that, there, as, if,
  not), or all of them when that leaves none; each once. Under 2 characters: no search.
- **Match**: a query word matches a document word that starts with it, or, for a query word of 4+ letters ending in
  "s", one that starts with it minus the s (decks → deck).
- **Fields and weights**: FAQ question 4, keywords 3, topic title 2, answer 1; guide lead 3, subheading 2, section
  title 2, text 1. Each query word scores its best field's weight.
- **Score**: 2 × the sum, +6 when every word of the query (stop words too) starts consecutive words of the question
  (or the entry's lead, else its subheading), +1 for an FAQ. Every query word must match; when no document matches all
  of them (two or more words), the documents matching the most words, marked partial.
- **Order**: score, then FAQs before guide entries, then file order (FAQs, then the guide). At most 50.
