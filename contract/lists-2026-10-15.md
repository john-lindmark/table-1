# Decks and cubes: client contract (L3, 2026-10-15)

Server: migration `20261015140000_card_lists.sql`. Every client (iOS, web, Android) reads and writes lists through these RPCs, so a list made or edited on one device shows on all of them after a sync.

## Model
- **List:** `{id, kind: deck|cube, name, format, versions[]}`. The `id` is a UUID the client generates, so creating is idempotent and can show immediately.
- **Versions:** oldest first. The current contents are the newest version. History is never rewritten:
  - edits within 10 minutes of the previous edit extend that version
  - anything later starts a new one
  - restoring appends a copy of the old version ("Restored vN")
- **Version shape:** `{version, note, at (epoch seconds), entries: [[card_id, board, qty], …]}`.
- **Boards:**

  | Value | Shown as | Applies to |
  |---|---|---|
  | `main` | Main deck / Main | decks and cubes |
  | `side` | Sideboard | decks only |
  | `maybe` | Considering | decks and cubes |
  | `commander` | Commander | decks only |

  Considering never counts as missing and never counts against the copies you own.

## RPCs (authenticated)

| Call | Does |
|---|---|
| `list_create(p_id, p_kind, p_name, p_format, p_entries?, p_note?)` | Creates the list as v1. Calling again with the same id returns the existing list. |
| `list_edit(p_list_id, p_ops)` | `p_ops`: `{card_id, board, delta}`, `{card_id, board, qty}` (0 removes) or `{card_id, from, to}` (move every copy). Up to 2000 ops. |
| `list_restore(p_list_id, p_version)` | Appends a copy of that version. |
| `list_update(p_list_id, p_name?, p_format?)` | Renames or changes the format. |
| `list_delete(p_list_id)` | Deletes for every device; other devices learn about it on sync. |
| `lists_changes(p_after, p_limit=100)` | `{lists, next, more}`: lists changed after the cursor, each with every version; deleted ones arrive as `{id, deleted: true}`. |

Every write returns the whole list as the server now holds it. Replace the local copy with it; the server decides the version grouping.

## Sync
Keep `cursor`, the highest `seq` applied, per account, and a device cache of the lists. Sync on app open, on returning to the Library and on returning to the foreground: call `lists_changes(cursor)` until `more` is false. Show a change at once if you like, but always replace it with the server's answer, and on an error re-sync.

## Rules the server enforces
- A cube has no sideboard or commander.
- Every `card_id` must be a known printing.
- At most 999 copies per line, 1000 lines per list, and 500 lists per account.
- Account deletion removes all lists.

## Display
Group lines by section, then by type for decks (Creatures, Planeswalkers, Instants, Sorceries, Artifacts, Enchantments, Battles, Lands, Other) or by color for cubes (White, Blue, Black, Red, Green, Multicolor, Colorless, then Lands). The grid view keeps the same headers.

## Finishes and printings (2026-10-15)

- An entry is `[card_id, board, qty]` (non-foil) or `[card_id, board, qty, finish]` (`foil` / `etched`). A line is printing × section × finish, so a deck can hold 2 foil and 2 non-foil copies of one printing as two lines. Three-element entries (all history before this change) mean non-foil. A line asking for a finish its printing doesn't come in (`cards.finishes`) is saved in one it does: non-foil first, then foil, then etched, merging with a line that already has it (2026-10-22, migration `20261022100000_list_finish_fallback.sql`, applied to live 2026-10-22 with John's OK and smoke-tested in a rolled-back transaction with the six printings that blocked his cube; before, `list_create` / `list_edit` refused the whole list, so a Cube Cobra cube with a foil-only Secret Lair listed without a finish never saved).
- **Unsaved lists (iOS, 2026-10-22):** iOS shows a new list at once and saves it behind; a list the server hasn't saved yet is kept in `ListsStore.unsaved` (with the last error) in the device cache, sent again on every sync, and its screen says so ("This cube isn't saved to your account yet: …"). Changes made meanwhile go with it. Rankings of an unsaved cube say it isn't saved instead of asking the server. A cache from before this gets one full pull, and any list the server didn't send is treated as unsaved. Web and Android only show a list once the server has saved it.
- Every `list_edit` op takes an optional `finish` (default `nonfoil`): `{card_id, board, finish?, delta | qty}`, `{card_id, finish?, from, to}`.
- New op `{card_id, board, finish?, to_card_id?, to_finish?, qty?}` moves `qty` copies (default all) of a line to another printing and/or finish in the same section. Clients use it from **Change printing or finish** (edit mode → tap a line): pick how many copies, then a printing's finish. Since 2026-10-18 also from card detail opened from the list (`contract/change-printing-2026-10-18.md`). Same printing + another finish splits the line.
- Missing counts a line as covered only by owned copies of that printing **in that finish** (collection rows are already printing × finish × condition × language).
- `card_list_entries` has a `finish` column; its key is `(list_id, board, card_id, finish)`.
- Lists and finders add cards as non-foil of the original paper printing by default (catalog contract, `original`).

## Languages (2026-10-25)

Deck and cube lines name a language (John, 2026-10-25), so a cube can list a Japanese copy of an English printing, and
Add to collection adds copies in that language (contract/list-to-collection-2026-10-22.md).

- A line is printing × section × finish × language. An entry is `[card_id, board, qty]`, `[card_id, board, qty, finish]`
  (both English) or `[card_id, board, qty, finish, lang]` for any other language (the finish is then always written).
  Older entries and older apps keep working: they read the first four elements, and a line they add is English.
- A non-English printing (`cards.lang`) is always its own language; `list_write` saves it so whatever the entry says.
  Migration `20261025200000_list_languages.sql` relabelled the 6 existing lines (4 lists) that listed one, rewriting
  only their current version.
- `list_edit` ops take an optional `lang` (default `en`); `{from, to}` keeps the line's language; the move op takes
  `to_lang` (default the line's own) beside `to_card_id` / `to_finish`. An invalid code is refused (22023).
- `card_list_entries` has a `lang` column; its key is `(list_id, board, card_id, finish, lang)`.
- Clients: list rows say the language when it isn't English ("JA"); version history shows it; card detail opened
  from a deck or cube has a Language cell (Set · Language · Finish · Section) that moves the copies in view to another
  language (one swap op); Change printing keeps the line's language unless the new printing has its own; Add to
  (Deck/Cube) from card detail lists the copy in the language on screen; adds from search and scans use the printing's
  or scanned language; a collapsed card reads "N versions" when its lines share a printing.
- Missing still goes by printing + finish over every language (owned Japanese copies cover an English line).
- Not yet: shared decks/cubes on profiles and share links, exports (Arena, Moxfield, MTGO, Cube Cobra) and imports
  don't carry the language.

## Export (2026-10-17)

Every deck and cube screen has **Export** (below Version history; hidden while editing or until the card data is in). It exports the **current version**, with card names, set codes and collector numbers from the local catalog pack; lines whose printing isn't in the pack are left out with a note. Built on iOS (`Library/ListExport.swift`, share sheet), web (`lib/listExport.ts`, copy or download) and Android (`library/ListExport.kt`, `ACTION_SEND`; files through the `export/` FileProvider path).

| Format | For | Out as | Content |
|---|---|---|---|
| `arena` | decks | text (copy) | `Commander`, `Deck`, `Sideboard` sections, blank line between; `4 Lightning Bolt (2X2) 117`. No finishes (foil and non-foil of one printing are one line), no Considering. |
| `moxfield` | decks | text (copy) | Arena's layout plus `*F*` / `*E*` and a `Maybeboard` section for Considering. |
| `mtgo` | decks | `.txt` file | Main deck, a blank line, the sideboard; names only. The commander goes in the sideboard (MTGO's Commander convention); no Considering. |
| `text` | decks, cubes | text (copy) | `4 Lightning Bolt`, merged across printings and finishes. Section headers (`Commander`, `Deck`/`Main`, `Sideboard`, `Considering`) only when the list has more than one section. |
| `cubecobra` | cubes | `.csv` file | Cube Cobra's own export columns (from its source, `CSV_HEADER`): `name,CMC,Type,Color,Set,Collector Number,Rarity,Color Category,status,Finish,board,maybeboard,image URL,image Back URL,tags,Notes,MTGO ID,Custom,Voucher,Artist`. One row per copy, main then Considering (`board` `mainboard`/`maybeboard`, `maybeboard` `false`/`true`), `Finish` `Non-foil`/`Foil`/`Etched`, quoting as Cube Cobra writes it, the first `—` in Type as `-` (Cube Cobra swaps it back). Color Category, status, images, tags, notes, MTGO ID and artist stay empty so Cube Cobra fills them. CRLF line ends. |

Rules shared by every client:
- **Names** as Arena, Moxfield and Cube Cobra spell them: front face for double-faced, adventure, flip, prepare and omen cards (`Delver of Secrets`), both halves for split cards and rooms (`Fire // Ice`): a card keeps its full name when every face's type is Instant or Sorcery (with any subtype except Adventure/Omen) or `Enchantment — Room`, which matches exactly Scryfall's `split` layout (checked against `card_oracles`, 2026-10-17).
- **Printings**: `(SET) number` only when the set code is 2–6 letters/digits and the collector number is letters, digits, `★ † Φ _ -` (what list-import reads); otherwise the line has the name alone.
- **Order**: by exported name, then set, collector number, finish (non-foil, foil, etched), comparing UTF-16 code units. Text ends with one `\n`.
- File names: the list's name with only letters, digits, spaces, `-` and `_` (`deck`/`cube` if nothing is left), `.txt` or `.csv`.
- Telemetry `list_exported {kind, format, cards, left}`.

**Round trip.** `testdata/list-export/` has a deck and a cube (`lists.json`, real printings from the test pack) and the exact file each format must produce; iOS, web and Android tests render the lists and compare byte for byte. `supabase/functions/list-import/parse.test.ts` (in `./test.sh`) parses every file and checks it reads back as the same lines (`parsed.json`), and each client's tests resolve `parsed.json` through its import resolver: Moxfield and Cube Cobra come back as the identical entries, Arena as the same printings without finishes or Considering, MTGO and plain text with every card found and the same counts per section.

**list-import changes** (`parse.ts`, needs a deploy of `list-import`): pasted text whose first line has a `name` column and a set, collector number, board or maybeboard column is read as a CSV (Cube Cobra's export and bulk-upload CSV, or a Moxfield/ManaBox collection CSV): one copy per row unless there's a count/quantity column, `board` (or legacy `maybeboard`) picks the section, `Finish`/`Foil` the finish. Collector numbers may also hold `Φ` and `_` (five printings in the catalog have them).

## Stats (2026-10-17)

Client-only: every number comes from the catalog pack (type line, mana cost, mana value, colors, legality code, and
since 2026-10-18 produced mana and token links) and `card_prices_get`; no stats RPC. The math is one pure module per client (`DeckStats.swift`,
`deckStats.ts`, `DeckStats.kt`), checked against the shared cases in `testdata/deck-stats/cases.json`, which
`testdata/deck-stats/make_cases.py` (an independent Python reference) writes. Change the reference first, regenerate,
then make all three clients pass.

**Where.** A **Stats** row on the deck or cube screen (hidden while editing) carries a one-line summary: decks
"24 lands · avg MV 1.72 · $1,535.36", cubes "W 44 · U 56 · …" (M multicolor, C colorless, L lands). Tapping it opens
Stats; the sample hand, draw odds and sample pack are each one more tap. Web routes:
`/library/list/:id/stats`, `…/stats/hand`, `…/stats/odds`, `…/stats/pack`.

**Decks** read the main deck and commander ("the deck"); sideboard and Considering are left out except where noted.
- A card's types come from its **front face** (before ` // `), the part before ` — `: Creature, Planeswalker, Instant,
  Sorcery, Artifact, Enchantment, Battle, Land. A card counts once for each type (Dryad Arbor is a Land and a
  Creature). A land is any card whose front face is a Land; a spell // land MDFC counts as its spell.
- **Curve:** non-land cards by mana value (`floor(cmc)`, 0 … 6, 7+), split creatures / other spells.
- **Average mana value** with and without lands.
- **Pips:** every `{…}` symbol in the whole mana cost (all faces); a symbol counts once for each of W U B R G among its
  `/`-separated parts (`{W/U}` → W and U, `{2/W}` → W, `{R/P}` → R). Shares are of all colored pips.
- **Sources:** cards in the deck that make mana, from the pack's `produced` field (contract/catalog-2026-10-14.md):
  lands and any card with a permanent face (Creature, Planeswalker, Artifact, Enchantment, Battle, Land), so dorks,
  rocks and a spell // land card count, rituals don't. A card counts once for each color it makes; `F` (a land that
  searches for any basic land: Evolving Wilds, Prismatic Vista) makes the colors of the deck's basic lands (by their
  basic land types), nothing in a deck without basics. Fetch lands that name land types make those colors (Polluted
  Delta U and B). The table lists the colors the deck has pips in (or, with no colored pips, the colors its sources make), so a
  fetch land's other land type (Bloodstained Mire's Swamp in Boros) adds no row; the share is of all sources; a row below gives the total, how many aren't lands and how
  many make colorless. Lands (not basics) that make no mana (Maze of Ith) are counted in a note. A card the pack has
  no `produced` for (a pack built before 2026-10-18) falls back to the old reading: lands by their basic land types on
  any face (Plains W, Island U, Swamp B, Mountain R, Forest G); the note then says card data is still updating.
- **Legality:** per format, over main deck, sideboard and commander (copies added up by name). In order: Banned, Not
  legal, Restricted to 1 (restricted with more than one copy), then copy limits: Singleton in Commander and Canadian
  Highlander, More than 4 copies in Standard, Pioneer, Modern, Legacy, Vintage, Pauper and Premodern. Basics, cards
  that allow any number (Relentless Rats, Rat Colony, Shadowborn Apostle, Persistent Petitioners, Dragon's Approach,
  Slime Against Humanity, Hare Apparent, Templar Knight, Cid, Timeless Artificer) and capped ones (Seven Dwarves 7,
  Nazgûl 9) are exempt. The deck's own format lists each failing card with its reason; the other checked formats show
  "Legal" or a count. Formats without a code (cube, other) aren't checked. The list screen's own warning is unchanged.
- **Price:** main deck, sideboard and commander at TCGplayer market for each line's printing and finish; copies with no
  price are counted ("14 unpriced").
- **Tokens:** the token cards the main deck, commander and sideboard make (the pack's `tokens` field, Scryfall
  `all_parts`), in name order, each with its type line and the cards that make it with their copies. Token cards
  with the same name (two different Spirit tokens) are listed apart. Cubes don't show tokens.

**Sample hand** (London mulligan): the main deck (commander excluded) is shuffled and seven drawn. A mulligan reshuffles
everything, draws seven, then asks for one card per mulligan taken to go on the bottom (tap a card); Draw is off until
that's done and then takes the next card from the top. At most six mulligans. Cards drawn after keeping are tagged
"Drawn".

**Draw odds:** hypergeometric P(at least k of a group) with N = main deck size, K = copies in the group, and cards seen
by turn T = 7 + T on the draw, 7 + T − 1 on the play. Groups: each card type present, then each card by name. A
table shows turns 1–8 for the same k.

**Cubes** read the main section only.
- **Color balance** by the card's **colors** (the pack's `colors`, not its mana cost; the list's own group headers use
  the mana cost, so a card like Ancestral Vision or a devoid card can sit differently): White … Green, Multicolor,
  Colorless, and Lands (any land) on their own.
- **Curve per color:** mana value columns per color group (lands left out).
- **Type mix:** type counts as for decks, with their share of the cube.
- **Asfan:** expected copies per pack = pack size × copies with the characteristic ÷ cube size, by color group, card
  type or mana value (with Lands). Pack size defaults to 15 (1–30, kept per device).
- **Sample pack:** that many cards drawn without replacement.

**Random numbers:** mulberry32 seeded with 32 bits, bounded ints by multiply-shift (`next × bound >> 32`), Fisher–Yates
from the end; copies are expanded in list order. The same seed gives the same hand on every client (the tests replay
one); the apps seed from the system generator.

**Telemetry** (contract/telemetry-2026-10-15.md): screens `deck_stats`, `cube_stats`, `sample_hand`, `draw_odds`,
`sample_pack`; events `sample_hand_used`, `draw_odds_used`, `sample_pack_used`, `cube_asfan_changed`.

**Budget:** every stat on a 540-card cube: iOS Debug 14 ms (budget 30), web 0.7 ms (5), Android JVM 1.7 ms (10).
