# Decks and cubes: client contract (L3, 2026-10-15)

Server: migration `20261015140000_card_lists.sql`. Every client (iOS, web, Android) reads and writes lists through these RPCs, so a list made or edited on one device shows on all of them after a sync.

## Model
- **List:** `{id, kind: deck|cube, name, format, versions[]}`. The `id` is a UUID the client generates, so creating is idempotent and can show immediately.
- **Versions:** oldest first. The current contents are the newest version. History is never rewritten:
  - edits within 10 minutes of the previous edit extend that version
  - anything later starts a new one
  - restoring appends a copy of the old version ("Restored vN")
- **Version shape:** `{version, note, at (epoch seconds), entries: [[card_id, board, qty], …]}`.
- **Boards:**

  | Value | Shown as | Applies to |
  |---|---|---|
  | `main` | Main deck / Main | decks and cubes |
  | `side` | Sideboard | decks only |
  | `maybe` | Considering | decks and cubes |
  | `commander` | Commander | decks only |

  Considering never counts as missing and never counts against the copies you own.

## RPCs (authenticated)

| Call | Does |
|---|---|
| `list_create(p_id, p_kind, p_name, p_format, p_entries?, p_note?)` | Creates the list as v1. Calling again with the same id returns the existing list. |
| `list_edit(p_list_id, p_ops)` | `p_ops`: `{card_id, board, delta}`, `{card_id, board, qty}` (0 removes) or `{card_id, from, to}` (move every copy). Up to 2000 ops. |
| `list_restore(p_list_id, p_version)` | Appends a copy of that version. |
| `list_update(p_list_id, p_name?, p_format?)` | Renames or changes the format. |
| `list_delete(p_list_id)` | Deletes for every device; other devices learn about it on sync. |
| `lists_changes(p_after, p_limit=100)` | `{lists, next, more}`: lists changed after the cursor, each with every version; deleted ones arrive as `{id, deleted: true}`. |

Every write returns the whole list as the server now holds it. Replace the local copy with it; the server decides the version grouping.

## Sync
Keep `cursor`, the highest `seq` applied, per account, and a device cache of the lists. Sync on app open, on returning to the Library and on returning to the foreground: call `lists_changes(cursor)` until `more` is false. Show a change at once if you like, but always replace it with the server's answer, and on an error re-sync.

## Rules the server enforces
- A cube has no sideboard or commander.
- Every `card_id` must be a known printing.
- At most 999 copies per line, 1000 lines per list, and 500 lists per account.
- Account deletion removes all lists.

## Display
Group lines by section, then by type for decks (Creatures, Planeswalkers, Instants, Sorceries, Artifacts, Enchantments, Battles, Lands, Other) or by color for cubes (White, Blue, Black, Red, Green, Multicolor, Colorless, then Lands). The grid view keeps the same headers.

## Finishes and printings (2026-10-15)

- An entry is `[card_id, board, qty]` (non-foil) or `[card_id, board, qty, finish]` (`foil` / `etched`). A line is printing × section × finish, so a deck can hold 2 foil and 2 non-foil copies of one printing as two lines. Three-element entries (all history before this change) mean non-foil. The finish must exist for that printing (`cards.finishes`), else `list_edit` / `list_create` refuse with "That printing doesn't come in that finish".
- Every `list_edit` op takes an optional `finish` (default `nonfoil`): `{card_id, board, finish?, delta | qty}`, `{card_id, finish?, from, to}`.
- New op `{card_id, board, finish?, to_card_id?, to_finish?, qty?}` moves `qty` copies (default all) of a line to another printing and/or finish in the same section. Clients use it from **Change printing or finish** (edit mode → tap a line): pick how many copies, then a printing's finish. Same printing + another finish splits the line.
- Missing counts a line as covered only by owned copies of that printing **in that finish** (collection rows are already printing × finish × condition × language).
- `card_list_entries` has a `finish` column; its key is `(list_id, board, card_id, finish)`.
- Lists and finders add cards as non-foil of the original paper printing by default (catalog contract, `original`).

## Stats (2026-10-17)

Client-only: every number comes from the catalog pack (type line, mana cost, mana value, colors, legality code) and
`card_prices_get`; nothing new on the server. The math is one pure module per client (`DeckStats.swift`,
`deckStats.ts`, `DeckStats.kt`), checked against the shared cases in `testdata/deck-stats/cases.json`, which
`testdata/deck-stats/make_cases.py` (an independent Python reference) writes. Change the reference first, regenerate,
then make all three clients pass.

**Where.** A **Stats** row on the deck or cube screen (hidden while editing) carries a one-line summary: decks
"24 lands · avg MV 1.72 · $1,535.36", cubes "W 44 · U 56 · …" (M multicolor, C colorless, L lands). Tapping it opens
Stats; the sample hand, draw odds and sample pack are each one more tap. Web routes:
`/library/list/:id/stats`, `…/stats/hand`, `…/stats/odds`, `…/stats/pack`.

**Decks** read the main deck and commander ("the deck"); sideboard and Considering are left out except where noted.
- A card's types come from its **front face** (before ` // `), the part before ` — `: Creature, Planeswalker, Instant,
  Sorcery, Artifact, Enchantment, Battle, Land. A card counts once for each type (Dryad Arbor is a Land and a
  Creature). A land is any card whose front face is a Land; a spell // land MDFC counts as its spell.
- **Curve:** non-land cards by mana value (`floor(cmc)`, 0 … 6, 7+), split creatures / other spells.
- **Average mana value** with and without lands.
- **Pips:** every `{…}` symbol in the whole mana cost (all faces); a symbol counts once for each of W U B R G among its
  `/`-separated parts (`{W/U}` → W and U, `{2/W}` → W, `{R/P}` → R). Shares are of all colored pips.
- **Sources:** lands only, read from their basic land types on any face (Plains W, Island U, Swamp B, Mountain R,
  Forest G). The pack has no produced-mana field, so fetch and utility lands make nothing here; the screen says how
  many lands it couldn't read (lands with no basic land type that aren't basics). Mana rocks and dorks aren't counted.
- **Legality:** per format, over main deck, sideboard and commander (copies added up by name). In order: Banned, Not
  legal, Restricted to 1 (restricted with more than one copy), then copy limits: Singleton in Commander and Canadian
  Highlander, More than 4 copies in Standard, Pioneer, Modern, Legacy, Vintage, Pauper and Premodern. Basics, cards
  that allow any number (Relentless Rats, Rat Colony, Shadowborn Apostle, Persistent Petitioners, Dragon's Approach,
  Slime Against Humanity, Hare Apparent, Templar Knight, Cid, Timeless Artificer) and capped ones (Seven Dwarves 7,
  Nazgûl 9) are exempt. The deck's own format lists each failing card with its reason; the other checked formats show
  "Legal" or a count. Formats without a code (cube, other) aren't checked. The list screen's own warning is unchanged.
- **Price:** main deck, sideboard and commander at TCGplayer market for each line's printing and finish; copies with no
  price are counted ("14 unpriced").
- **Tokens:** not shown. The pack has no token links (Scryfall `all_parts`); add them to the pack first.

**Sample hand** (London mulligan): the main deck (commander excluded) is shuffled and seven drawn. A mulligan reshuffles
everything, draws seven, then asks for one card per mulligan taken to go on the bottom (tap a card); Draw is off until
that's done and then takes the next card from the top. At most six mulligans. Cards drawn after keeping are tagged
"Drawn".

**Draw odds:** hypergeometric P(at least k of a group) with N = main deck size, K = copies in the group, and cards seen
by turn T = 7 + T on the draw, 7 + T − 1 on the play. Groups: each card type present, then each card by name. A
table shows turns 1–8 for the same k.

**Cubes** read the main section only.
- **Color balance** by the card's **colors** (the pack's `colors`, not its mana cost; the list's own group headers use
  the mana cost, so a card like Ancestral Vision or a devoid card can sit differently): White … Green, Multicolor,
  Colorless, and Lands (any land) on their own.
- **Curve per color:** mana value columns per color group (lands left out).
- **Type mix:** type counts as for decks, with their share of the cube.
- **Asfan:** expected copies per pack = pack size × copies with the characteristic ÷ cube size, by color group, card
  type or mana value (with Lands). Pack size defaults to 15 (1–30, kept per device).
- **Sample pack:** that many cards drawn without replacement.

**Random numbers:** mulberry32 seeded with 32 bits, bounded ints by multiply-shift (`next × bound >> 32`), Fisher–Yates
from the end; copies are expanded in list order. The same seed gives the same hand on every client (the tests replay
one); the apps seed from the system generator.

**Telemetry** (contract/telemetry-2026-10-15.md): screens `deck_stats`, `cube_stats`, `sample_hand`, `draw_odds`,
`sample_pack`; events `sample_hand_used`, `draw_odds_used`, `sample_pack_used`, `cube_asfan_changed`.

**Budget:** every stat on a 540-card cube: iOS Debug 14 ms (budget 30), web 0.7 ms (5), Android JVM 1.7 ms (10).
