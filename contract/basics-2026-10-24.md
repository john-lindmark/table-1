# Basic lands: owned, valued, never missing (2026-10-24)

John, 2026-10-24: basics can be added to the collection and their value counts there, but a deck or cube that lists
basics never calls them missing and doesn't count their value. Client-only; no server change.

## Which cards

A **basic** is any printing of a card whose type line has the **Basic** supertype (Plains, Island, Swamp, Mountain,
Forest, Wastes and the Snow-Covered ones), read from the catalog pack's type line. Clients build the set of basic
printings once per pack (`basicCardIds`); until the pack is loaded the set is empty and the old counts show.

## Rules

- **Collection:** unchanged. Basics are added, counted, sorted and valued like any other card (All cards, the
  collection value, binders, trades, the Collection value widget).
- **Never missing.** A deck or cube line of a basic never counts as missing, however many you own:
  - the deck/cube row on the Decks and Cubes lists ("3 missing" / "All owned");
  - the line on the deck/cube screen: "Owned N" when you own some, nothing when you own none, never "missing" or the
    short colour on the count;
  - **Wants → Missing from decks and cubes**, and the "· N missing" count on the Library home and Wants title;
  - trade gets tagged "Missing · <list>";
  - **Add to collection → Missing** (Every card still adds them, as listed).
- **Wants you add yourself stay.** A want for a basic is something you asked for, so it shows and trades meet it.
- **Deck and cube value:** Stats → price leaves basics out, priced or not (an unpriced basic isn't counted as
  unpriced). The collection's value still counts the basics you own.
