# One row for a card in a list (2026-11-15)

John: "add card images similar to the limited rows for constructed cards", then "Can we actually unify all the designs
for cards in lists. like in wants, limited insights, decks, constructed insights?" and "don't need to show the ownership
status or finish in the decks/cubes, and don't need to show the types or printings in the binder view, don't need to
show the ranking number or number in hand in the limited insights list". Client-only; no server change.

## The row
Every card in a list is drawn by the Library's card row (iOS `CardRow` in `Library/CardImages.swift`, web and Android
their Library card row):

- the **whole card** as the thumbnail (36 pt wide; foil sheen for foils), never an art crop;
- the name, and on **Insights rows only** the card's **mana cost** beside it (12 pt symbols); Library rows show no cost;
- up to two lines of data (uppercase labels);
- a value on the right (a count, a percentage, a price).

Before this, Insights drew its own rows (Limited: place number, a 52 × 38 art crop, cost and rarity on the data line;
Constructed: no picture). Those are gone.

## What each list shows

| List | Data lines | Right |
|---|---|---|
| Deck / cube line | issue, Canadian Highlander points, language, condition (no ownership, no finish) | count, red when short |
| Deck / cube collapsed card | issue, "N printings" / "N versions" | count, red when short |
| Binder (list layout) | none | count |
| Wants | unchanged (which printing; price trend) | unchanged |
| Limited Top cards, Limited search | rarity letter (M R U C) | the sort's number, vs average |
| Limited, other sets | the set | – |
| Limited pair · best cards | rarity · colors | win rate in hand |
| Constructed rising / falling | `in 28% of decks · was 17%` / `3.4 copies` | ▲ / ▼ points |
| Constructed New set | `in 12% of decks` / `most in <archetype>` | share |
| Constructed archetype cards | copies | share |
| Constructed card search | as before (`hitDetail`) | – |
| Ban study replacements | `in <archetype>` / `4.0% → 9.1% of lists` | – |

Ownership in decks and cubes is shown by the count turning red when short (as on grid and stack tiles) and by Missing;
the finish shows as the thumbnail's sheen.

## Pictures in Insights
The thumbnail printing comes from the card catalog (asked for like the Library does): Limited and New set rows use the
card's printing in that set (English first), else its usual picture (original paper printing, the catalog's cover);
every other Insights row uses the usual picture. iOS: `CardFace.load(oracleIds:set:)` / `CardFace.load(names:)` and
`.loadsFaces(_:set:into:)` in `Insights/LimitedViews.swift`. Until the catalog is in, rows draw an empty card.
