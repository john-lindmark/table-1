## 2. What is secret, and where it lives

A trade secret is only what (a) isn't public, (b) has value from that, and (c) you take reasonable steps to keep.
Anything shipped inside the apps or the web bundle can be read by a determined person, so it is protected by
copyright and the Terms, not by secrecy.

| Asset | Lives | Secret today? |
|---|---|---|
| Pairing engine, standings, playoffs, pods | Edge function + copied into the web bundle | No (web copy; public repo) |
| Archetype rules (75 + 36 + 28 seeded, hand-tuned) | Database | Only once the repo is private (seeds are in migrations) |
| Insights pipeline: tiers, weights, ingest, singleton filter, spice | Edge functions, SQL | Only once the repo is private |
| Moderation prompt and policy | Edge function | Only once the repo is private |
| Scanner matcher, ranking engine, deck stats | In the apps | No; copyright + Terms only |
| Scan report set (labelled real scans) | `testdata/scan/reports` | Only once the repo is private |
| User data, events history, meta database | Supabase | Yes (RLS, RPC-only writes) |

Steps that count as "reasonable": private repo; 2FA on GitHub, Supabase, Cloudflare, Apple, Google; no collaborator
without a signed agreement (`templates/`); keys in the Keychain and function secrets only (already true); the
confidentiality line in `LICENSE`.

## 3. Other people's IP that Table 1 stands on

### Wizards of the Coast: Fan Content Policy (company.wizards.com/en/legal/fancontentpolicy, last updated 2017-11-15)

- Fan Content must be free: no payments, subscriptions, **or email registration** required to access it.
  Sponsorships, ad revenue and donations are allowed. Affiliate links aren't mentioned.
- Don't use Wizards' logos and trademarks (the policy's § 4). Naming the game to say what the app is for is ordinary
  descriptive use, but no Magic logos, mana-symbol branding or planeswalker mark in our icon or store art.
- The notice we show is the required one.
- Wizards can end the permission at any time for any reason.

Open questions for a lawyer:
1. **Sign-in.** Most of Table 1 needs an account. Card pages, Insights, shared links and `/s` standings are open
   signed out on the web, but the apps are not. Whether a tournament tool is "Fan Content" at all, and whether a free
   account counts as "email registration to access", is unclear. Companion apps with accounts are common and
   tolerated; none of that is a right.
2. **Charging.** A paid tier would have to charge for *our* service (running events, storage, analytics), never for
   access to cards, images or Wizards' content, and even that sits outside what the policy plainly permits. Decide
   this before any pricing work; consider asking Wizards for written permission.
3. **Affiliate income** from TCGplayer: closest to "ad revenue", not addressed by name.

### Scryfall (scryfall.com/docs/api)

- No paywall on Scryfall data; with accounts, users should reach card data anonymously or with free accounts. ✔
- Must add value, not repackage. ✔  No new games. ✔  No implying endorsement; no Scryfall logo. ✔
- Accurate `User-Agent` and `Accept` headers on API calls. ✔ on the server (`Table1Events/1.0 (table-1.site)`); the
  web keeps the browser's. **Check** that the iOS and Android on-demand calls (rules text, advanced search) name the app.
- Images: don't cover or crop the artist name / copyright; don't distort, blur, desaturate or color-shift; don't add
  our own logos or stamps; **with an art crop, show the artist and copyright in the same interface, or the full card.**

Places to check against the image rules:

| Where | Question |
|---|---|
| Collection home hero strip and shelves, Events art, tracker backgrounds (art crop under a 60 % scrim) | Is a scrim "color-shifting / covering"? Where is the artist named? The full card is one tap away, which may or may not be "the same interface". |
| **Card icon widget** (art crop with the T1 mark on it) | The clearest conflict: our logo on card art, no artist shown. |
| Deck image, Top N image (count badges on cards; the T1 mark in the header) | Badges cover part of the card; the mark is beside, not on, the cards. |
| Foil / etched sheen over card images | An overlay effect on the image. |
| Discord pictures (`deck-image`, `ranking-image`) | Same as Deck image. |

Cheap fix that covers most of it: an "Art: <artist> · © Wizards of the Coast" line wherever an art crop is the
subject (the pack already carries `artist`), and no T1 mark on top of art in the widget.

### 17Lands (17lands.com/public_datasets)

Public datasets are CC BY 4.0 unless noted. Commercial use is allowed with attribution. We credit "Data from 17Lands"
on every Limited screen. ✔ Add a link and the license name on the web credit to be complete.

### TopDeck.gg (topdeck.gg/docs/tournaments-v2)

Free API; requires a visible credit **with a link** back to topdeck.gg ("Data provided by TopDeck.gg"). We credit by
name in `sourcesCredit`, and the web credit links to topdeck.gg ✔; check the apps' credit is a link too. There are separate
Developer Terms at topdeck.gg/developer-terms that were not read: read them.

### Magic Online decklists (mtgo.com)

Read by fetching public pages hourly at about a page a second. No API, no permission. Facts and results aren't
copyrightable, but the site's terms of use probably forbid automated collection, and Daybreak/Wizards could block or
object. Highest-risk source after Wizards itself. Options: ask Daybreak; keep rates low and identify the client
honestly; be ready to drop the source.

### Melee via fbettega/MTG_decklistcache (GPL-3.0)

We read data files from a public GitHub repo; we never call Melee. Two separate points:
- GPL covers the repo's *code*. We run none of it and link none of it, so the GPL does not reach our code. Whether
  the data files are licensed at all is unclear (facts mostly aren't copyrightable).
- The repo's scraper signs in to Melee to collect them, which Melee's terms very likely forbid. We benefit from that
  one step removed. `table-1-context/docs/melee-request-2026-10-28.md` (asking Melee for read access) is drafted and
  **not sent**; sending it is the clean fix.

### Cube Cobra

Terms forbid harvesting. We only fetch a cube when a user asks (import, sync). ✔ The cube corpus for Spice is
correctly left empty; `cubecobra-request-2026-10-28.md` is drafted and not sent.

### TCGplayer / Impact, Cardmarket

Affiliate program terms apply (disclosure; no misleading links; no bidding on their brand). Prices reach us through
Scryfall, which is the permitted route; TCGplayer gives us no API. Cardmarket EUR shown converted to USD and marked
"from Cardmarket" also comes through Scryfall.

### Apple, Google, Discord, Anthropic

SF Mono is never bundled: iOS uses the system font, the web names it in a font stack (it shows only where the
visitor already has it), Android uses its own monospace, server pictures use JetBrains Mono. ✔ Sign in with Apple / Google / Discord marks follow each brand's button rules: worth one look.
Anthropic's terms assign output to the customer; that doesn't create copyright where the law gives none (finding 9).
