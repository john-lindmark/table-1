Layer names

Name a layer #field; text layers get text, shapes and frames get image or color fills. Text component properties with these names work too.

Text: #name #mana_cost #type_line #oracle_text #flavor_text #pt #power #toughness #loyalty #cmc #set #set_name #collector_number #rarity #artist #price #price_foil #price_eur #colors #color_identity #keywords #released_at, or any Scryfall field.

Image fill: #image #art #image_normal #image_png #border_crop. Color fill: #color.

Prefix back. for the back face: #back.name, #back.art.
